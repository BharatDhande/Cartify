# Cartify – E-Commerce App

## Description

**Cartify** is a fully functional e-commerce platform designed to provide users with a seamless shopping experience. It features user authentication, a product catalog, shopping cart functionality, an admin panel, and order management. The app uses `Java`, `Spring Boot`, `MySQL`, and `REST API` for the back-end and offers a scalable solution for managing products, users, and orders.

## Features

- **User Authentication**: Secure login and registration for users.
- **Product Management**: Admin can add, update, and delete products.
- **Order Management**: Users can place, view, and track orders.
- **Shopping Cart**: Users can add, update, and remove items from their shopping cart.
- **Admin Panel**: Admins can manage users, products, and orders.
- **REST API**: For seamless interaction between the front-end and back-end.
